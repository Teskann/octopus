Plan technique · MCP + Agent

Piloter l'éditeur vidéo depuis Claude Code

Comment exposer toutes les commandes de l'éditeur (transcription, sous-titres, clips, cadrage, scènes, styles/presets, overlays, export) sous forme d'une API MCP, plus la vision (transcription horodatée + captures d'écran à un timecode), pour qu'un agent comme Claude Code repère lui-même les meilleures séquences et fabrique les clips.

✅ Statut : implémenté dans le dépôt. Les deux endpoints backend (GET /{id}/frame, GET /{id}/transcript), l'endpoint des presets intégrés (GET /api/presets/builtin), le mode capture composée (?mode=preview), le serveur MCP (mcp_server/, 29 outils), le .mcp.json et la bannière de rechargement de l'éditeur sont écrits et testés (endpoints + pont MCP validés bout-à-bout avec une vraie vidéo). Reste à votre charge : pip install "mcp[cli]", vérifier /mcp, et lancer l'app. Ce document décrit la conception et sert de mode d'emploi.

1L'idée & le résultat visé

Aujourd'hui, tout l'état d'un projet (segments horodatés au mot, style de sous-titres, cadrage, scènes, coupes, overlays, clips) vit dans un project.json et est déjà modifiable via une API REST FastAPI. L'éditeur React n'est qu'un client de cette API.

Conséquence heureuse : pour donner « le clavier » à un agent, il n'y a presque rien à réécrire. Il suffit d'emballer l'API REST dans un serveur MCP (le protocole que Claude Code parle pour appeler des outils) et d'ajouter deux capacités qui manquent aujourd'hui : une lecture compacte de la transcription et une capture d'image à un timecode (la « vision » de l'agent).

Ce que l'agent pourra faire, en langage naturel : « Lis la transcription, trouve les 5 passages les plus percutants, crée un clip pour chacun (bornes au mot près), corrige les fautes d'orthographe et les erreurs de contexte de Whisper, applique le preset Bold Anton, recadre en 9:16, puis exporte. » — chaque phrase devient un ou plusieurs appels d'outils MCP.

2L'architecture recommandée

Le point clé de conception : le serveur MCP doit être un client HTTP mince vers le FastAPI déjà lancé (:8000), pas un second processus qui importe app.store directement.

Pourquoi passer par HTTP et pas importer store ? app/store.py garde un cache projet en mémoire (« single uvicorn worker ») protégé par un verrou. Un serveur MCP séparé qui lirait/écrirait project.json en direct aurait son propre cache : les deux processus se marcheraient dessus (l'un écrase les écritures de l'autre). En parlant au FastAPI par HTTP, il n'y a qu'un seul cache, qu'un seul chemin d'écriture, et toute la logique (migrations, re-timing des mots, validations) est réutilisée telle quelle.

« Tout texte, bouton, combobox » : les combobox et sliders de style/cadrage sont des champs de style/frame ; les boutons d'action (Traduire, Exporter) sont des endpoints POST. La couverture est donc quasi complète — seules la lecture compacte et la vision manquent.

4Ce qu'il faut ajouter au backend

Deux petits endpoints dans app/editor.py. Rien d'autre côté serveur.

4.1 — Capture d'image à un timecode (la « vision » de l'agent)

Un GET qui renvoie une image JPEG de la vidéo source à l'instant t, extraite par ffmpeg (déjà une dépendance). C'est ce qui permet à l'agent de voir le contenu à un moment donné : repérer un temps fort visuel, vérifier un cadrage, confirmer qui parle.

Avant — pas de capture

@router.get("/{project_id}/video")
def get_video(project_id: str) -> FileResponse:
    project = store.get(project_id)
    ...

Après — nouvel endpoint /frame

import subprocess
from fastapi.responses import Response
@router.get("/{project_id}/frame")
def get_frame(project_id: str, t: float,
              width: int = 480) -> Response:
    project = store.get(project_id)
    if project is None:
        raise HTTPException(404, "Unknown project")
    src = store.source_path(project)
    proc = subprocess.run(
        ["ffmpeg","-y","-hide_banner","-loglevel","error",
         "-ss", f"{max(t,0):.3f}", "-i", str(src),
         "-frames:v","1","-vf",f"scale={width}:-2",
         "-c:v","mjpeg","-f","image2","pipe:1"],
        capture_output=True)
    if proc.returncode or not proc.stdout:
        raise HTTPException(500, proc.stderr[-400:].decode())
    return Response(proc.stdout, media_type="image/jpeg")
Deux variantes possibles. Ci-dessus = image source brute (rapide, idéale pour « comprendre » le contenu). Si vous voulez que l'agent voie exactement le rendu final (sous-titres + recadrage + scènes), on peut réutiliser l'infra d'export : ouvrir la route ?render=1 dans Chrome headless, appeler window.__render.seek(t) et screenshot — même mécanisme que app/render.py, mais une seule frame. C'est plus lourd (Chrome + Vite requis) ; commencez par la frame source, ajoutez le rendu composité plus tard si besoin.

4.2 — Transcription compacte (économie de tokens)

GET /{id} renvoie tout le projet, y compris chaque mot horodaté — vite volumineux. Un endpoint dédié renvoie juste ce dont l'agent a besoin pour raisonner sur le découpage.

@router.get("/{project_id}/transcript")
def get_transcript(project_id: str) -> list[dict]:
    project = store.get(project_id)
    if project is None:
        raise HTTPException(404, "Unknown project")
    return [
        {"id": s["id"], "start": s["start"], "end": s["end"],
         "text": s["text"], "translation": s.get("translation", "")}
        for s in project["segments"]
    ]

Les timecodes au mot restent accessibles via GET /{id} quand l'agent veut des bornes de clip au mot près.

5Le serveur MCP & son catalogue d'outils

Un nouveau paquet Python (ex. mcp_server/) qui déclare des outils MCP, chacun faisant un appel HTTP au FastAPI. Voici le catalogue proposé — pensé pour l'agent, donc granulaire (créer un clip, corriger un sous-titre) plutôt que « patche ce gros JSON ». Le serveur fait le read-modify-write des tableaux (clips, overlays, scene_cuts) pour vous.

6Squelette du serveur MCP

Avec le SDK Python officiel (pip install "mcp[cli]" httpx) et FastMCP. Extrait représentatif — les autres outils suivent le même moule.

"""mcp_server/__main__.py — pont MCP ⇄ API REST de l'éditeur.
Lancer : python -m mcp_server   (Claude Code le lance en stdio)."""
import os, httpx
from mcp.server.fastmcp import FastMCP, Image

API = os.environ.get("TRANSCRIPT_API", "http://localhost:8000")
mcp = FastMCP("transcript")
http = httpx.Client(base_url=API, timeout=60)

# ---- lecture ---------------------------------------------------------------
@mcp.tool()
def list_projects() -> list[dict]:
    """Liste les projets (id, nom, statut, durée)."""
    return http.get("/api/projects").raise_for_status().json()

@mcp.tool()
def get_transcript(project_id: str) -> list[dict]:
    """Segments horodatés compacts : id, start, end, text, translation."""
    r = http.get(f"/api/projects/{project_id}/transcript")
    return r.raise_for_status().json()

@mcp.tool()
def get_frame(project_id: str, t: float, width: int = 480) -> Image:
    """Capture la frame de la vidéo à l'instant t (secondes). Renvoie une image."""
    r = http.get(f"/api/projects/{project_id}/frame",
                 params={"t": t, "width": width})
    r.raise_for_status()
    return Image(data=r.content, format="jpeg")

# ---- édition des sous-titres ----------------------------------------------
@mcp.tool()
def edit_segment(project_id: str, segment_id: str, text: str | None = None,
                 translation: str | None = None,
                 start: float | None = None, end: float | None = None) -> dict:
    """Corrige un sous-titre : orthographe/contexte (text), traduction, ou bornes.
    Les timings au mot sont recalculés côté serveur quand `text` change."""
    patch = {k: v for k, v in
             {"text": text, "translation": translation,
              "start": start, "end": end}.items() if v is not None}
    r = http.patch(f"/api/projects/{project_id}/segments/{segment_id}", json=patch)
    return r.raise_for_status().json()

# ---- clips (read-modify-write du tableau `clips`) -------------------------
@mcp.tool()
def create_clip(project_id: str, start: float, end: float, name: str = "Clip") -> dict:
    """Crée un clip [start, end] (secondes). Utilisez les bornes de mots pour être précis."""
    proj = http.get(f"/api/projects/{project_id}").raise_for_status().json()
    clip = {"id": os.urandom(6).hex(), "name": name,
            "start": float(start), "end": float(end)}
    clips = proj["clips"] + [clip]
    http.patch(f"/api/projects/{project_id}", json={"clips": clips}).raise_for_status()
    return clip

# ---- style / presets ------------------------------------------------------
@mcp.tool()
def set_style(project_id: str, style: dict) -> dict:
    """Fusionne des réglages de légende (font, font_size, highlight_color, position,
    uppercase, box_enabled, translation_scale, max_lines, ...)."""
    proj = http.get(f"/api/projects/{project_id}").raise_for_status().json()
    merged = {**proj["style"], **style}
    r = http.patch(f"/api/projects/{project_id}", json={"style": merged})
    return r.raise_for_status().json()["style"]

# ---- export ---------------------------------------------------------------
@mcp.tool()
def export_clips(project_id: str, clip_ids: list[str] | None = None) -> list[dict]:
    """Lance le rendu MP4 des clips (liste vide = tous). Suivre avec render_status."""
    r = http.post(f"/api/projects/{project_id}/renders",
                  json={"clip_ids": clip_ids or []})
    return r.raise_for_status().json()

if __name__ == "__main__":
    mcp.run()   # transport stdio par défaut
Bon réflexe : des docstrings claires sur chaque @mcp.tool() — c'est ce que l'agent lit pour choisir l'outil. Décrivez les unités (secondes), les effets de bord (recalcul des timings), et quand utiliser quoi (« bornes de mots pour être précis »).

7Brancher Claude Code

Déclarez le serveur MCP pour ce dépôt. Le plus simple, un fichier .mcp.json à la racine du projet (versionnable, partagé) :

{
  "mcpServers": {
    "transcript": {
      "command": "python",
      "args": ["-m", "mcp_server"],
      "env": { "TRANSCRIPT_API": "http://localhost:8000" }
    }
  }
}

Ou en une commande (scope projet) :

claude mcp add transcript --scope project \
  --env TRANSCRIPT_API=http://localhost:8000 \
  -- python -m mcp_server

Vérifiez le branchement dans une session : /mcp liste le serveur transcript et ses outils. Les outils apparaissent sous le nom mcp__transcript__<outil>.

Prérequis à lancer avant l'agent : le FastAPI doit tourner (./scripts/run-app.sh → :8000). Pour exporter, il faut aussi Vite (:5173) + Chrome (voir scripts/setup-render.sh), comme pour l'export manuel. Pour seulement découper/éditer/capturer, le FastAPI + ffmpeg suffisent.

8Exemple de session agent

Ce que vous tapez à Claude Code, et ce qu'il fait derrière :

« Ouvre mon dernier projet. Lis la transcription, repère les 3 moments les plus percutants (punchlines, retournements), et crée un clip de 20–40 s pour chacun avec des bornes propres. Corrige au passage les fautes de Whisper. Applique le preset Bold Anton et recadre en 9:16. Montre-moi une capture au milieu de chaque clip, puis exporte. »
  1. list_projects → prend le plus récent ; get_transcript pour lire tout le texte horodaté.
  2. Raisonne sur les segments, choisit 3 fenêtres. Récupère les words[] via get_project pour caler start/end sur des frontières de mots.
  3. Repère des coquilles évidentes → edit_segment (text corrigé ; les timings au mot sont recalculés).
  4. create_clip ×3 avec les bornes choisies.
  5. apply_preset("Bold Anton") puis set_frame(aspect="9:16").
  6. get_frame(t=milieu du clip) ×3 → voit les images, vérifie le cadrage, ajuste set_frame si un visage est coupé.
  7. export_clips → puis render_status en boucle jusqu'aux MP4 téléchargeables.

9Pièges & limites

  • Rafraîchissement de l'UI — géré. L'éditeur sonde le projet toutes les 5 s et, s'il détecte un changement externe (l'agent édite via la même API), affiche une bannière « Ce projet a été modifié en dehors de l'éditeur → Recharger / Ignorer ». La détection compare le contenu serveur à vos éditions locales et n'alerte que sur un écart stable (donc pas votre propre sauvegarde débouncée). « Recharger » réinitialise tout l'état depuis le serveur.
  • Débounce inverse. À l'inverse de l'humain (qui sauvegarde avec 400 ms de débounce), l'agent écrit immédiatement via l'API. Évitez d'éditer manuellement le même projet en même temps que l'agent : dernier écrivain gagne.
  • Un seul worker uvicorn. Le cache mémoire n'existe que dans ce processus — c'est précisément pourquoi le serveur MCP passe par HTTP (§2) et n'ouvre pas project.json lui-même.
  • Coût en tokens. Préférez get_transcript (compact) à get_project pour raisonner ; ne tirez les words[] que quand des bornes précises sont requises. Limitez la largeur des captures (width=480) — inutile de renvoyer du 1080p à l'agent.
  • Capture = source brute. La v1 de get_frame montre la vidéo avant sous-titres/recadrage. Pour juger le rendu final, ajoutez la variante « frame composée » (Chrome headless, §4.1).
  • Autorisations. Au premier lancement, Claude Code demande l'autorisation d'utiliser chaque outil MCP. Vous pouvez pré-autoriser les outils lecture seule (list_*, get_*) et garder une confirmation sur l'export.
